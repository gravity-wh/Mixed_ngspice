## 目标
修复 real_to_str() 的 static buf 导致所有多值 printf 输出被污染。修复后 01_nmos_dc 的 Ids/gm/gds/vth/vdsat 五个值不再相同。

## 根因
float_spice.c:2126: `static char buf[32]` — 所有 real_to_str() 调用返回同一个缓冲区指针。在 printf 的多个 %s 参数中，后求值的覆盖前一个。

## 修复
改为 4 槽环形缓冲区：

```c
static const char *real_to_str(REAL v, char fmt, int prec) {
    static char buf[4][32];  // 环形缓冲, 4槽足够任何单行printf
    static int idx = 0;
    char *b = buf[idx]; idx = (idx + 1) & 3;
    // ... 原有格式化逻辑, 写入 b 而非 buf ...
    return b;
}
```

## 受影响行
- :2181-2183: NMOS/PMOS model info 打印 (vth0/u0/toxe 显示同一值)
- :2347-2353: 器件参数表 (Ids=gm=gds=vth=vdsat)
- 所有多参数 printf 调用 (~15 处)
