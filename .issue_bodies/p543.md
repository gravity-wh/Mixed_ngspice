## 交付物
.meas语句解析器 + AVG/MAX/MIN/PP/RMS求值器。

## 实现路径
1. 数据结构: Meas{name,type,analysis,signal,from,to,...}, MAX_MEAS=64
2. 解析: .meas TRAN vout_final AVG v(out) FROM=1n TO=100n
   支持dot-command和.control两种上下文
3. 求值函数 eval_meas():
   AVG → 波形窗口内平均
   MAX/MIN → 波形窗口内极值
   PP → MAX-MIN
   RMS → sqrt(AVG(x^2))
4. main()输出: "meas_name = value" 格式打印

## 测试标准
- .meas TRAN vout AVG: 计算值与手动计算<1%差异
- .meas TRAN vout MAX > AVG
- FROM/TO范围正确截取
- cvtss2sd <= 5
