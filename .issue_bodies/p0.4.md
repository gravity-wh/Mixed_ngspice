## 目标
消除 param_subst() 和 AC 输出中的 (double) 强转，减少 cvtss2sd 指令。

## 位置 1: param_subst() :1014
```c
// 当前:
snprintf(rep, 32, "%.6g", (double)c->param_vals[i]);

// 修复: 用 real_to_str 替代 snprintf %g
char *rts = (char*)real_to_str(c->param_vals[i], 'g', 6);
snprintf(rep, 32, "%s", rts);
```

## 位置 2: AC 输出 :1866
```c
// 当前:
printf("%.1f %.1f\n", (double)fstart, (double)fstop);

// 修复: 用 real_to_str
printf("%s %s\n", real_to_str(fstart, 'f', 1), real_to_str(fstop, 'f', 1));
```

## 注意
printf 的 %f/%g 对 float 参数会自动提升为 double（C varargs 规则），即使不加 (double) 强转也会产生 cvtss2sd。修复后使用 real_to_str 输出字符串，彻底消除。

## 验证
```bash
make -C float_spice && make -C float_spice verify
# cvtss2sd 计数应减少
```
