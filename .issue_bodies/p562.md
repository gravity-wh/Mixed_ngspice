## 交付物
eval_expr() 运算符支持: +, -, *, /, ^ 带优先级爬山。

## 实现路径
扩展 P5.6.1 的eval_expr():

expr = term (('+'|'-') term)*
term = power (('*'|'/') power)*
power = unary ('^' power)?
unary = '-' unary | primary

优先级: +- (1) < */ (2) < ^ (3) < unary- (4)

运算符执行全部用REAL:
  ^ → powf(base, exp)
  / → 检查除数 != 0, 用fabsf(denom)<1e-30 ? 0 : a/denom

## 测试标准
- "1+2*3" → 7.0 (优先级正确)
- "2^3" → 8.0
- "(1+2)*3" → 9.0 (括号)
- "a+b*v(z)" → 组合: 变量+变量*电压
- cvtss2sd <= 5
