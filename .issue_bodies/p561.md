## 交付物
eval_expr() 基础框架 — 数字解析、变量查找、v(node)/i(vsrc)访问。

## 实现路径
文件: float_spice/float_spice.c, 新函数 (~line 560, parse_eng附近)

递归下降: const char **p 字符光标
1. 跳过空白
2. 首个字符分支:
   数字或'.': parse_eng(*p) → REAL, 推进p
   '(': 递归expr, 期望')'
   'v': 期望'(nodename)' → find_or_add_node → v[node]
   'i': 期望'(vsrcname)' → 查找vsrc → iv[idx]
   字母: 变量查找 let_names[] (P5.1)
   '-': 递归unary, 取负
3. 错误处理: 返回 0.0f, 不崩溃

## 测试标准
- eval_expr("1.5") → 1.5
- eval_expr("v(d)") 当前v[d]=1.1 → 1.1
- eval_expr("-v(y)") v[y]=0.5 → -0.5
- eval_expr("abc") 未知变量 → 0.0 (安全降级)
- cvtss2sd <= 5
