## 交付物
noise_solve() 函数: 每频率计算输出噪声谱密度。

## 实现路径
文件: float_spice/float_spice.c, ac_solve()之后, 新函数

核心算法 (伴随法):
1. 构建AC导纳矩阵Y (复用ac_assemble_matrix)
2. 转置: Y^T
3. RHS: 输出节点单位激励 br[out_node]=1.0
4. 求解 Y^T * v_adj = e_out → lu_solve_complex()
5. 对每个MOSFET:
   - S_ids = thermal + flicker 噪声
   - H2 = |v_adj[d] - v_adj[s]|^2 = dv_r^2 + dv_i^2
   - S_out += H2 * S_ids
6. onoise = sqrtf(S_out) V/sqrt(Hz)

## 测试标准
- 单MOSFET: onoise@1kHz > 0
- onoise随频率递减
- 闪烁噪声区: f×10 → onoise ~/sqrt(10)
- 无NaN
- cvtss2sd <= 5
