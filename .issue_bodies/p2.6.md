## 目标
补全本征电容模型参数 (Cgs/Cgd/Cgb)，提升 TRAN 精度。

## 参数 (8)
capmod, acde, moin, noff, cgsl, cgdl, ckappas, ckappad, cf

## 当前状态
已有基础 Meyer 模型 (Cgs/Cgd/Cgb 三电容)。capmod=0 时使用 Meyer。capmod=2 (PTM 默认) 使用电荷守恒模型。

## 需补全
```
if (capmod == 2):
  // 电荷守恒 C-V 模型:
  Qg = Weff*Leff*Coxe * (Vgsteff - 0.5*Abulk*Vdseff/...) // 栅电荷
  Cgs = dQg/dVs + cgso*Weff  // 叠加+本征
  Cgd = dQg/dVd + cgdo*Weff
  Cgb = dQg/dVb + cgbo*Leff
  // acde=1: 使用偏压依赖的 C-V (更精确)
  // noff>0: 亚阈值区 C-V 平滑
```
此参数对 TRAN 瞬态行为影响显著 (电容充放电)，但对 DC OP 无影响。

## 验证
TRAN 波形 V(out) 的上升/下降时间与 ngspice 一致 (<10% 偏差)。
