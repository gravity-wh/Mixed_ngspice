## 目标
支持 `.lib 'filename' sectionname` 格式。PTM .lib 当前只需要 `.include` 就能工作，但 SKY130 和某些 PDK 使用 `.lib` 分段格式。

## 解析
```
.lib 'model.lib' TT      → 打开 model.lib, 找到 .lib TT 段
.lib 'model.lib' mos_tt  → 找到 .lib mos_tt 段, 解析其中的 .model 卡
```
在 parse_netlist 中增加 `.lib` 处理分支:
```c
else if (!strncmp(s, ".lib ", 5)) {
    char fn[512], sec[64];
    if (sscanf(s, ".lib '%[^']' %63s", fn, sec) == 2 ||
        sscanf(s, ".lib %511s %63s", fn, sec) == 2) {
        parse_lib_section(c, fn, sec, dir);
    }
}
```

## 验证
SKY130 .lib 文件正确解析 sect ion 内的 .model 卡。
PTM .lib 保持兼容 (无 section 时全文件解析)。
