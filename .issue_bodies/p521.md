## 交付物
一个可独立测试的复数LU分解函数 lu_solve_complex()。

## 实现路径
文件: float_spice/float_spice.c, 紧接 lu_solve() 之后 (~line 121)。

关键算法:
1. 复数密集LU, REAL *ar[N*N], *ai[N*N] 并行存储实部和虚部
2. 按复数值大小 ar^2+ai^2 选主元
3. 复数除法: f_r = (aik_r*pk_r + aik_i*pk_i) / (pk_r^2+pk_i^2)
4. 复数消元: a[i][j] -= f * a[k][j] (复数乘法展开)
5. 复数回代: x = (rhs_r*ar + rhs_i*ai) / (ar^2+ai^2)

验证方法:
硬编码3x3实数矩阵 [[2,-1,0],[-1,2,-1],[0,-1,2]], RHS=[1,0,0]
解析解: x[0]=0.75, x[1]=0.5, x[2]=0.25

## 测试标准
- 编译零警告
- 3x3已知系统: x[0]=0.75, x[1]=0.5, x[2]=0.25 (误差 < 1e-5)
- 奇异矩阵返回 -1
- cvtss2sd <= 5 (无complex.h, 纯REAL运算)
