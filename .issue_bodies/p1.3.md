## 目标
bsim4_eval() 迁移率计算支持 mobMod=0/1/2 三种模式 + Coulomb散射(ud/eu) + 温度系数(ua1/ub1/uc1)。完成后单管 gm 与 ngspice 参考偏差 <5%。

## 涉及的参数 (10)
u0, ua, ub, uc, ud, eu, mobmod, ua1, ub1, uc1

## BSIM4 迁移率完整方程

```
Eeff = (Vgsteff + 2*Vth)/(3*toxe)   // 有效垂直电场

mobMod = 0 (默认, PTM 45nm 使用):
  Ua_total = Ua + Uc*Vbs
  分母 = 1 + Ua_total*Eeff + Ub*Eeff²
  if (Ud > 0): 分母 += Ud*(Eeff^eu)

mobMod = 1:
  Ua_total = Ua + Uc*Vbs
  分母 = 1 + Ua_total*(Vgsteff+2*Vth)/toxe + Ub*((Vgsteff+2*Vth)/toxe)²

mobMod = 2:
  分母 = 1 + (Ua + Uc*Vbs)*(Vgsteff/toxe) + Ub*(Vgsteff/toxe)²

ueff = U0 / 分母
```
