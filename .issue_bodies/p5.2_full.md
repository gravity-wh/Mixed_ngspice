## 目标
E源(VCVS): V(out)=gain*V(in)。MNA约束 v[p]-v[n]=gain*(v[cp]-v[cn])。

## E 源 MNA 戳记详解

```
E1 out+ out- in+ in- gain

约束方程: v[out+] - v[out-] = gain * (v[in+] - v[in-])

MNA 矩阵 (N×N, row_i = 新增的约束行):
  ┌           ┐
  │ J_nl  B  │  Δv    =  -f_nl - B*I
  │ B^T   0  │  ΔI    =  E - (v[p]-v[n])
  └           ┘

E 源在 B 矩阵中:   (区别于普通 Vsrc 的 ±1)
  B[i][out+]  = +1
  B[i][out-]  = -1
  B[i][in+]   = -gain   ← E 源特有! 控制电压反馈
  B[i][in-]   = +gain   ← E 源特有!

B^T (转置):
  B^T[out+][i] = +1
  B^T[out-][i] = -1
  B^T[in+][i]  = -gain
  B^T[in-][i]  = +gain

RHS[i] = gain*(v[in+]-v[in-]) - (v[out+]-v[out-])
       = 期望值 - 当前值 (驱动 Newton 校正)
```

## 实现位置
float_spice.c dc_solve() 矩阵组装段 (~line 1650, MNA 浮动 Vsrc 段后):
```c
// E source: treat as floating Vsrc with extra B entries
if (vs_is_float[j]) {
    // ... standard Vsrc B stamp ...
    // PLUS: for E source, add -gain/+gain for control nodes
    if (is_esource) {
        a[cp + row*N] -= gain;  // B[i][in+]
        a[cn + row*N] += gain;  // B[i][in-]
        a[row + cp*N]  -= gain; // B^T[in+][i]
        a[row + cn*N]  += gain; // B^T[in-][i]
    }
}
```
