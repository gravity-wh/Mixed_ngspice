## 交付物
G源(VCCS)解析 + 表达式求值 + 数值Jacobian戳记。

## 实现路径
1. Gsource结构体: char name[32]; int p,n; char expr[MAX_LINE];
2. Circuit加: int ng; Gsource *gsrc;
3. parse_instance: Gx n+ n- value={expr} → 提取expr字符串
4. dc_solve戳记(~line 1190, 电流源之后):
   I_expr = eval_expr_str(gsrc.expr)
   rhs[p]+=I_expr; rhs[n]-=I_expr
   数值Jacobian: 扫描expr中v()引用, 对每节点:
     v[k]+=1e-6f; I_plus=eval; v[k]-=1e-6f
     dI/dV=(I_plus-I_expr)/1e-6f
     戳入a[p+k*N]+=dI/dV; a[n+k*N]-=dI/dV

- Newton收敛: 3G源电路 <20次迭代
- cvtss2sd <= 5
