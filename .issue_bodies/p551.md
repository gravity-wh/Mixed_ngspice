## 交付物
Diode数据结构和.model D解析。

## 实现路径
1. Diode结构体: char name[32]; int p, n; char model[32]; REAL area;
2. Circuit加: int nd; Diode *dio;
3. .model D: IS=1e-14, N=1.0, RS=0, CJO=0, VJ=0.7, M=0.5, BV=inf, IBV=1e-3
4. parse_instance: D1 n+ n- modelname [area=1.0]
5. find_model查找或使用默认model参数

## 测试标准
- 解析 D1 1 0 mydiode area=2.0: p=1, n=0, area=2.0
- model默认: IS=1e-14, N=1.0
- cvtss2sd <= 5
