## 目标
实现体-源/漏结二极管电流。Vbs≠0 时 (如共源放大器体效应) 产生漏电。

## 参数 (14)
jss, jsws, jswgs, njs, bvs, xjbvs, jsd, jswd, jswgd, njd, bvd, xjbvd, cj, mj

## 方程
```
// 体-源结:
Ibs = jss*Weff*Leff*(exp(Vbs/(njs*Vt))-1) + jsws*(Weff+Leff)*(exp(Vbs/(njs*Vt))-1)
// 体-漏结:
Ibd = jsd*Weff*Leff*(exp(Vbd/(njd*Vt))-1) + jswd*(Weff+Leff)*(exp(Vbd/(njd*Vt))-1)
// 击穿: if(|Vbs| > bvs) Ibs *= exp((|Vbs|-bvs)/xjbvs)
```
PTM 45nm LP: jss=0.0001, jsws=1e-11 → Vbs=0 时电流为 0，不影响 DC OP。

## 验证
Vbs=-0.5V: Ibs 应有微弱电流 (~1e-12 A 量级)。Vbs=0: Ibs=0。
