## 目标
P0.1 + P0.3 + P0.4 修复后，重跑全部 14 个电路的收敛和精度测试，确认修复有效。

## 操作
```bash
# 1. 重新编译
make -C float_spice && make -C float_spice verify

# 2. 逐个运行 14 电路
for f in test/circuits/mx/*.sp \
         test/circuits/01_single_nmos_45nm/test_dc.sp \
         test/circuits/01_single_nmos_45nm/test_dc_sweep.sp \
         test/circuits/02_single_pmos_45nm/test_dc.sp \
         test/circuits/02_single_pmos_45nm/test_dc_sweep.sp \
         test/circuits/04_ota_5transistor_45nm/test_dc.sp \
         test/circuits/05_opamp_2stage_miller_45nm/test_dc.sp \
         test/circuits/06_comparator_strongarm_45nm/test_tran.sp \
         test/circuits/03_ring_oscillator_17stage/test_tran.sp \
         test/circuits/07_bootstrap_switch_45nm/test_tran.sp; do
  echo "=== $f ==="
  timeout 30 ./float_spice/float_spice "$f" > /dev/null 2>&1 && echo "PASS" || echo "FAIL"
done

# 3. 精度验证 (01_nmos_dc)
./float_spice/float_spice test/circuits/01_single_nmos_45nm/test_dc.sp > /tmp/fs_p0v.log
build_fp64/src/ngspice --batch test/circuits/01_single_nmos_45nm/test_dc.sp > /tmp/ng_p0v.log
python scripts/compare_fp.py /tmp/fs_p0v.log /tmp/ng_p0v.log
```

## 成功标准
| 检查项 | 标准 |
|--------|------|
| 电路收敛 | ≥10/14 PASS（无 TIMEOUT, 无 NaN） |
| 器件参数 | Ids≠gm≠gds≠vth≠vdsat（P0.1 修复确认） |
| 模型参数 | NMOS: u0≠vth0≠toxe（P0.3 修复确认） |
| cvtss2sd | ≤5（P0.4 修复确认） |
| NMOS 单管精度 | gm/gds/vth/ids 与 ngspice 参考偏差 <20% |

## 如果部分电路仍失败
- 04_ota/05_opamp/06_comparator 仍收敛到零 → 开启 P1（BSIM4 方程补全）
- 单管精度 >20% → 优先级提升 P1.2-P1.4

## 预估: 30min | 依赖: P0.1 + P0.3 + P0.4
