## 目标
基于 P0.V 和 P1 的实测收敛数据，调优 gmin/cmin/source stepping 参数，使 04_ota (5T)、05_opamp (7T)、06_comparator (14T) 正确收敛。

## 方法
1. 先跑 P0.V，收集每个电路的收敛数据 (迭代次数、gmin stage、ramp)
2. 分析失败模式:
   - 收敛到零 → source stepping 起始值太大
   - 矩阵奇异 → gmin 太小
   - 收敛慢 (>200次迭代) → vlim 太紧
3. 调优参数:
   ```
   src_ramp[]   = {1e-4, 1e-3, 1e-2, 1e-1, 1.0}  // 加一档更小的起始
   gmin_stages  = {1e-7, 1e-9, 1e-10, 1e-12}       // 加一档更大的初始
   vlim 初始值  = 0.2V (更保守)
   max_iter     = 200 (增加迭代上限)
   ```
4. 逐个电路验证

## 验证
- 04_ota: VDD=1.1V, OUT≠0V
- 05_opamp: 7 MOSFET 全部非零 Ids
- 06_comparator: 14 MOSFET 全部非零 Ids
- 03_ringosc: 17-stage .subckt 正确展开+收敛
