## 目标
parse_include() 正确处理 BSIM4 .lib 文件中的续行（以 + 开头的行），使 PTM 模型卡的 115 个参数全部加载。

## 根因
float_spice.c:889-894: parse_include() 只匹配 `.model` 和 `.include` 行。以 `+` 开头的续行被静默跳过。PTM .lib 的第一行是 `.model nmos nmos level=54`，后面 100+ 行 `+param=value` 全部丢失。

## 修复
在 parse_include() 内部实现续行拼接，与 parse_netlist() 主解析器相同逻辑：

```c
static void parse_include(Circuit *c, const char *line, const char *pdir) {
    // ... 打开文件 ...
    char buf[MAX_LINE], acc[MAX_LINE*4] = "";  // accumulated model line
    int in_model = 0;
    
    while (fgets(buf, MAX_LINE, fp)) {
        char *s = buf;
        while (*s == ' ' || *s == '\t') s++;
        
        if (*s == '+') {
            // 续行: 拼接到累积缓冲区
            if (in_model) {
                int alen = strlen(acc);
                // 去掉 acc 末尾换行, 拼接 + 后的内容
                snprintf(acc + alen, sizeof(acc) - alen, " %s", s + 1);
            }
        } else if (!strncmp(s, ".model", 6)) {
            // 新 model 开始: 先处理上一个积压的 model
            if (in_model && acc[0]) {
                parse_model_line(c, acc);
            }
            strncpy(acc, s, sizeof(acc) - 1);
            in_model = 1;
        } else if (!strncmp(s, ".include", 8)) {
            if (in_model && acc[0]) { parse_model_line(c, acc); in_model = 0; }
            parse_include(c, s, idir);
        } else if (*s == '*' || *s == '\n' || *s == '\r' || *s == 0) {
            // 注释或空行: 结束当前 model, 继续
            if (in_model && acc[0]) { parse_model_line(c, acc); in_model = 0; }
        } else {
            if (in_model && acc[0]) { parse_model_line(c, acc); in_model = 0; }
        }
    }
    if (in_model && acc[0]) parse_model_line(c, acc);
    fclose(fp);
}
```
