## 交付物
E源(VCVS)解析+戳记 + Roessler电路端到端集成。

## 实现路径
1. Esource结构体: char name[32]; int p,n, cp,cn; REAL gain;
2. parse_instance: E1 out+ out- in+ in- gain
3. MNA戳记: E源是浮动Vsrc: v[p]-v[n] = gain*(v[cp]-v[cn])
   在MNA约束行: ar[row][p]=+1, ar[row][n]=-1, ar[row][cp]=-gain, ar[row][cn]=+gain
4. Roessler集成: dc_solve → .ic → tran_solve (G源+E源+.ic全部就位)
   08_roessler电路: 3个G源 + uic TRAN

## 测试标准
- E1 out 0 in 0 10: V(out)=10*V(in) +/- 0.1%
- 08_roessler: TRAN 200点无NaN,
- 最终v(x)/v(y)/v(z)有界(非INF)
- cvtss2sd <= 5
