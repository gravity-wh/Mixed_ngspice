## 目标
实现栅电阻模型 (RF 必需, DC 影响极小)。

## 参数 (1)
rgatemod

## 方程
```
if (rgatemod == 1):
  Rgate = rsg * Weff/(nf*Leff)  // 多指栅分布电阻
// 在矩阵戳记中串入栅节点
// PTM 45nm LP: rgatemod=1 (使能)
// DC 影响: 可忽略 (栅电流 = 0)
// 真正影响在 RF/高频 AC 分析中
```
此参数对 DC 无影响，仅在高频 AC 时 (复阻抗) 产生效应。标记为 done，暂不深入。

## 验证
DC: Rgate 不影响。AC: 栅阻抗实部 >0。
