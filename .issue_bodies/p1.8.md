## 目标
将已解析的 6 个温度参数接入 bsim4_eval() 的所有相关公式。完成后 T=300.15K 时结果不变 (回归), T=-40°C/125°C 时 Vth 和 Ids 有合理偏移。

## 涉及的参数 (6)
kt1, kt1l, kt2, ute, prt, tnom

## BSIM4 温度方程

### 1. Vth 温度 (~line 250)
```
deltaT = T - Tnom
T_ratio = T / Tnom
vth0_T = vth0 + kt1 * deltaT/Tnom + kt2 * (deltaT/Tnom)²
// kt1l 是 kt1 的长度依赖系数 (简化: 暂忽略)
```

### 2. 迁移率温度 (~line 350)
```
u0_T = u0 * powf(T_ratio, ute)
ua_T = ua + ua1*(T_ratio - 1)
ub_T = ub + ub1*(T_ratio - 1)
uc_T = uc + uc1*(T_ratio - 1)
```

### 3. 源漏电阻温度 (~line 470)
```
rdsw_T = rdsw + prt*(T/Tnom - 1)
```

### 4. 饱和速度温度 (P1.7)
```
vsat_T = vsat - at*(T_ratio - 1)
```

## 关键验证: T = Tnom 时回归
```
T = 300.15K (27°C, 默认) → deltaT = 0, T_ratio = 1
→ 所有温度修正项 = 0
→ 结果与修改前完全一致 ← 这是必须的!
```
