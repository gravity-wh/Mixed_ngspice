## 目标
解析并存储噪声参数，为 P4.3 Noise 引擎准备输入。

## 参数 (4)
noia, noib, fnoimod, tnoimod

## 方程
```
// 闪烁噪声 (fnoimod=1, PTM 默认):
S_id_flicker = noia * Ids / (freq * Coxe * Leff²)

// 热噪声 (tnoimod=0, 默认):
S_id_thermal = 4 * k_B * T * (2/3) * gm

// 总噪声 PSD (在 Noise 引擎中求和)
S_id_total = S_id_thermal + S_id_flicker
```
此 Issue 只要求参数正确加载 + 存储到 BSIM4Param。噪声 PSD 计算在 P4.3 中实现。

## 验证
bsim4_from_model(): noia=1e-10 (PTM LP), fnoimod=1 正确加载。
