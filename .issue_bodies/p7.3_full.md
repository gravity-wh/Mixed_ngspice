## 目标
compare_fp.py 加 parse_fs_meas() — 跨格式 .meas 比较。

## 解析逻辑
```python
def parse_fs_meas(text: str) -> dict:
    """Parse float_spice .meas output: 'meas_name = value' lines."""
    meas = {}
    for line in text.split('\n'):
        # 匹配: "gain_max = 2.100886e+01"
        m = re.match(r'^(\S+)\s*=\s*([-+]?\d+\.?\d*(?:[eE][-+]?\d+)?)', line.strip())
        if m:
            name = m.group(1)
            try:
                val = float(m.group(2))
                meas[name] = val
            except ValueError:
                pass
    return meas
```

## 集成到跨格式比较
在 compare_fp.py 主函数中添加:
```python
if is_float_spice_format:
    fs_meas = parse_fs_meas(fp32_text)
    ng_meas = parse_ng_meas(fp64_text)
    # 对齐 .meas name → 比较值
    for name in fs_meas:
        if name in ng_meas:
            rel_err = abs(fs_meas[name] - ng_meas[name]) / max(abs(ng_meas[name]), 1e-30)
            # 使用 meas 默认容差 2%
            if rel_err > 0.02:
                verdict = "FAIL"
```
