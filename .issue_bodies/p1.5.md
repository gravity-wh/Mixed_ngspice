## 目标
实现完整 BSIM4v5 亚阈值 + Vgsteff 双分支平滑过渡。完成后亚阈值区 Ids 与 ngspice 参考偏差 <2x (当前 2-10x)。

## 涉及的参数 (7)
nfactor, cdsc, cdscb, cdscd, voffcv, minv, cit

## BSIM4 亚阈值完整方程

### 1. 有效亚阈值摆幅因子
```
n_eff = nfactor + cdsc*Vds + cdscb*Vbs + cdscd*Vds²
```

### 2. Vgsteff (minv=0 经典单分支, 已有)
```
Vgst = Vgs - Vth - voffcv
Vgsteff = n_eff * Vt * ln(1 + exp(Vgst/(n_eff*Vt)))
```

### 3. Vgsteff (minv>0 双分支平滑过渡, 需实现)
```
Vgst_hi = 2.0 * n_eff * Vt  // 强反型参考点
// 经典分支: n_eff*Vt*ln(1+exp(Vgst/(n_eff*Vt)))
// 线性分支: fmaxf(Vgst, 0)
// minv_weight = 1/(1 + exp(-(Vgst - Vgst_hi)/(0.5*n_eff*Vt)))
// Vgsteff = minv_weight * classic + (1-minv_weight) * linear
```

### 4. Cd 耗尽电容修正 (cit 参数)
```
Cdep = √(εsi*q*Ndep/(2*φs))  // 耗尽电容
Coxe = εox/toxe               // 氧化层电容
n_eff += cit * Cdep / Coxe    // 接口态修正
```
