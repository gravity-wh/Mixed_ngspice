## 交付物
diode_eval() + dc_solve中的Newton迭代戳记。

## 实现路径
1. diode_eval(Vd, IS, N, Vt) → Id, gd:
   Vd_clamped = fminf(Vd, 50*N*Vt)  (防expf溢出)
   ev = expf(Vd_clamped/(N*Vt))
   Id = IS*(ev-1) + GMIN*Vd
   gd = IS*ev/(N*Vt) + GMIN
   NaN卫士: IS_NAN → Id=0, gd=1e-12

2. dc_solve矩阵戳记(~line 1180, MOSFET和电容之间):
   2x2电导块: a[p+p*N]+=gd; a[p+n*N]-=gd; a[n+p*N]-=gd; a[n+n*N]+=gd
   rhs[p]-=Id; rhs[n]+=Id

## 测试标准
- 二极管 Vd=0→0.7V: Id指数增长
- Vd=50*Vt: 不溢出 (clamp生效)
- Newton收敛: 含二极管电路3-5次迭代
- cvtss2sd <= 5
