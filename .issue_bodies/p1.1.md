## 目标
BSIM4Param 结构体从 51 参数扩展到 76 参数。bsim4_from_model() 补齐 25 个缺失参数的 model_get() 调用。bsim4_default() 设置正确的默认值。

## 当前状态
float_spice 已解析 51 参数。76 核心参数中缺少 25 个参数名。

## 需要新增的 25 参数 (分类)

### 阈值电压相关 (8)
dvt0w, dvt1w, dvt2w, etab, k3b, voff, nlx, cit

### 迁移率相关 (5)
ua1, ub1, uc1, ud, eu

### 漏极电流/CLM (5)
pdiblcb, drout, delta, a1, a2

### 亚阈值 (2)
cdsc, cdscd (已有但未接入公式)

### 源漏电阻 (2)
rsw, rdw, prwb

### 几何偏移 (2)
dwg, dwb

### 温度 (6) — 移至 P1.8
kt1, kt1l, kt2, ute, prt, at

实际新增参数个数: ~19 个 (温度 6 个在 P1.8 单独处理)

## 实现

### Step 1: BSIM4Param 结构体扩展
在 bsim4_default() 函数中添加新字段的默认值。参考 PTM 45nm LP .lib 中的值:

```c
// 阈值电压补充
.dvt0w = 0.0f, .dvt1w = 0.0f, .dvt2w = 0.0f,
.etab = 0.0f, .k3b = 0.0f, .voff = -0.13f,
.nlx = 1.74e-7f, .cit = 0.0f,
// 迁移率补充
.ud = 0.0f, .eu = 1.0f,
// CLM 补充
.pdiblcb = -0.005f, .drout = 0.5f, .delta = 0.01f,
.a1 = 0.0f, .a2 = 1.0f,
// 亚阈值补充
.cdsc = 0.0f, .cdscd = 0.0f,
// 源漏电阻补充
.rsw = 80.0f, .rdw = 80.0f, .prwb = 0.0f,
// 几何
.dwg = 0.0f, .dwb = 0.0f,
// 其他
.ags = 0.0f, .xpart = 0.0f, .binunit = 0.0f,
```

### Step 2: bsim4_from_model() 补充
为每个新参数添加 model_get() 调用:
```c
pp->dvt0w = model_get(m, "dvt0w", pp->dvt0w);
pp->dvt1w = model_get(m, "dvt1w", pp->dvt1w);
// ... 共 25 行
```
