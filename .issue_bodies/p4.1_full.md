## 目标
验证 lu_solve_complex() 正确性 + 完成复数矩阵求解器。

## 当前状态
框架已在 v2.5 中 (float_spice.c :154-199 lu_solve_complex 函数), 需用已知复数系统验证。

## 验证方法: 硬编码 3x3 复数测试

```c
// 测试矩阵 (复对称, 来自典型 RLC 电路):
// [2+j*0.5,  -1,       0     ]
// [-1,        2+j*0.5,  -1    ]
// [0,        -1,        2+j*0.5]
//
// RHS: [1+j*0, 0, 0]  (AC电流源激励节点0)
//
// 解析解 (手算):
// x[0] ≈ 0.451 + j*0.102
// x[1] ≈ 0.220 + j*0.058
// x[2] ≈ 0.115 + j*0.032

REAL ar[9] = {2, -1, 0,  -1, 2, -1,  0, -1, 2};
REAL ai[9] = {0.5, 0, 0,  0, 0.5, 0,  0, 0, 0.5};
REAL br[3] = {1, 0, 0}, bi[3] = {0, 0, 0};
REAL xr[3], xi[3];
int ok = lu_solve_complex(3, ar, ai, br, bi, xr, xi);
// ok == 0 (成功)
// fabsf(xr[0] - 0.451f) < 1e-3, fabsf(xi[0] - 0.102f) < 1e-3
```

## 额外测试: 奇异矩阵

REAL ar_sing[4] = {1, 1, 1, 1};  // 秩1矩阵
