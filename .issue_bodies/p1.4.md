## 目标
实现完整 BSIM4v5 漏极电流方程 + 5 层 Early 电压栈。完成后单管 gds 与 ngspice 参考偏差 <10%。

## 涉及的参数 (15)
pclm, pdiblc1, pdiblc2, pdiblcb, drout, pvag, pscbe1, pscbe2, delta, a0, a1, a2, ags, vsat, lambda(默认0)

## BSIM4 Ids + Early 电压完整方程

### 1. Abulk (体电荷系数)
```
Ab0 = 1 + K1/(2√(φs-Vbs)) * (A0*Leff/(Leff+2√(xj*toxe)) * ...)
Abulk = Ab0 / (1 + ags*Vgsteff*(Leff/(Leff+2√(xj*toxe)))²)
```

### 2. Vdsat (饱和电压)
```
EsatL = 2 * vsat / (ueff * Leff)
Vdsat = (Vgsteff + 2*Vt) * EsatL / (Abulk * (Vgsteff + 2*Vt) + EsatL)
```

### 3. Vdseff (平滑过渡)
```
Vdseff = Vdsat - 0.5*(Vdsat-Vds-delta + √((Vdsat-Vds-delta)² + 4*delta*Vdsat))
```

### 4. Ids0 (基本漏极电流)
```
Ids0 = β * (Vgsteff - Abulk*Vdseff/2) * Vdseff / (1 + Vdseff/EsatL)
其中 β = ueff * Coxe * Weff/Leff
```

### 5. 五层 Early 电压栈
```
Vasat  = ...  (基本)
VACLM  = (1/pclm + Abulk*EsatL*Leff/(Vgsteff*Vdsat)) * (Vds-Vdseff)  // CLM
VADIBL = (Vgsteff + 2*Vt) * (1 - Abulk*Vdsat/(Abulk*Vdsat+Vgsteff+2*Vt)) 
         / (pdiblc2 * pdiblc1) * exp(-dsub*Leff/(2*lto))             // DIBL
VADITS = 1/pdiblc1 * exp(-dsub*Leff/(2*lto))                         // DITS
VASCBE = Leff * exp(pscbe1*litl/(Vds-Vdseff)) / pscbe2              // SCBE

Vaeff = harmonic_sum(Vasat, VACLM, VADIBL, VADITS, VASCBE)
谐和求和: 1/Vaeff = 1/Vasat + 1/VACLM + 1/VADIBL + 1/VADITS + 1/VASCBE
```

### 6. 最终 Ids
```
Ids = Ids0 * (1 + (Vds-Vdseff)/Vaeff)
```
