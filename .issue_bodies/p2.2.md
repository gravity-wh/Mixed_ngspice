## 目标
实现 GIDL (Gate-Induced Drain Leakage) 基础模型。高 Vds 时栅-漏重叠区隧穿电流。

## 参数 (4)
agidl, bgidl, cgidl, egidl

## 方程
```
Vdg = Vds - Vgs
if (Vdg > 0):
  Igidl = agidl * Weff * (Vdg/toxeff)² * exp(-bgidl*toxeff/|Vdg|)
// 作为漏-体漏电流加入 RHS
```
PTM 45nm LP: agidl=0.0002 → 有微小影响。VDD=1.1V 时通常 <0.1% Ids。

## 验证
Vds=1.1V vs Vds=0.5V: gds 在高 Vds 时因 GIDL 略有增加。
