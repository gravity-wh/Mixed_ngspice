## 目标
bsim4_eval() 中的 Vth 计算从简化版升级为完整 BSIM4v5 方程。完成后单管 vth 与 ngspice 参考偏差 <1%。

## 涉及的参数 (16)
vth0, k1, k2, k3, k3b, w0, dvt0, dvt0w, dvt1, dvt1w, dvt2, dvt2w, dsub, eta0, etab, voff, nlx

## BSIM4 Vth 完整方程

```
Vth = Vth0 + ΔVth_body + ΔVth_SCE + ΔVth_DIBL + ΔVth_NW + ΔVth_LPE

1. 体效应 (已有基础版, 需补全):
   Vth_body = Vth0 + K1*(√(φs-Vbs) - √φs) - K2*Vbs
   其中 φs = 2*Vt*ln(Ndep/ni), ni = 1.45e10

2. 短沟效应 SCE (需补全 dvt0w/dvt1w/dvt2/dvt2w):
   lt = √(εsi*toxe*Xdep/εox) * (1 + dvt2*Vbs)
   θ = exp(-dvt1*Leff/(2*lt)) + 2*exp(-dvt1*Leff/lt)
   ΔVth_SCE = -dvt0 * θ * (Vbi - φs)
   宽度依赖: 同样公式用 dvt0w/dvt1w/dvt2w 替换, 乘以 toxe/Weff 因子

3. DIBL (需补全 etab):
   lto = √(εsi*toxe*Xdep/εox)
   ΔVth_DIBL = -(eta0 + etab*Vbs) * Vds * exp(-dsub*Leff/lto)

4. 窄宽效应 NW (需补全 k3b):
   ΔVth_NW = (K3 + K3b*Vbs) * toxe/(Weff + W0) * φs

5. LPE 口袋注入 (需补全 nlx):
   ΔVth_LPE = K1 * (√(1 + nlx/Leff) - 1) * √φs
```
