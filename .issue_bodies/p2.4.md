## 目标
实现体电阻网络模型，使体偏压分布更精确（大尺寸功率管必需）。

## 参数 (5)
rbodymod, rbdb, rbsb, rbpb, rbps, rbpd

## 方程 (rbodymod=1, 简化)
```
// 体电阻网络将 body 节点拆分为多个内部节点
// 简化版: 体接触 → 内部节点间串电阻
// PTM 45nm LP: rbodymod=1, rbdb=15, rbsb=15, rbpb=5
// 小尺寸器件影响小, 大尺寸 (W>10um, m>10) 时影响偏压分布
```
对于大多数音频/射频电路 (W<5um)，此参数组的 DC 影响 <0.1%。优先级较低。

## 验证
M=50 的大尺寸 LDO pass transistor: 有/无体电阻 → Vth 差异 <2mV。
