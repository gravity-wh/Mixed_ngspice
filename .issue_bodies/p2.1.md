## 目标
实现栅隧穿电流 (Gate Tunneling) 基础模型。tox=1.8nm 的 PTM 45nm LP 影响较小，但 tox=1.25nm 的 HP 版本必需。

## 参数 (7)
igcmod, aigc, bigc, cigc, nigc, ntox, toxref

## 方程 (简化为只实现 igcmod=1)
```
Vox = Vgs - Vfb  // 氧化层压降
ToxRatio = toxe/toxref * (1 + ntox*(T-300)/300)
igc = Weff*Leff * aigc * (Vox/toxref)² * exp(-bigc*toxref/|Vox|)
// 在矩阵戳记中作为栅-源/漏/体漏电流加入 RHS
```
如果 igcmod=0 (PTM 45nm LP 默认): 跳过, 返回 0。

## 验证
PTM 45nm LP: igcmod=0 → 无影响。PTM 45nm HP: igcmod=1 → Ids 微小变化 (<1%)。
