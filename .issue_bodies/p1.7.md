## 目标
补全速度饱和的温度依赖 (at) 和沟道长度调制的 a1/a2 参数。完成后 vdsat 与 ngspice 参考偏差 <5%。

## 涉及的参数 (4)
vsat, at, a1, a2

## BSIM4 方程

### 1. 速度饱和温度依赖
```
vsat_T = vsat - at*(T/Tnom - 1)   // vsat 随温度升高而降低
EsatL = 2 * vsat_T / (ueff * Leff)
```

### 2. a1/a2: Vdsat 修正系数
```
// a1, a2 用于调整 Vdsat 表达式中的 λ 因子:
lambda_term = a1*Vgsteff + a2
Vdsat_enhanced = Vdsat_basic * (1 + lambda_term/(Vgsteff + 2*Vt))
```
