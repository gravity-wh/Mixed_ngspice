## 目标
SKY130 噪声微调参数 — 扩展 P2.7 的 MOSFET 噪声 PSD 公式。

## 参数 (6): rnoia, rnoib, tnoia, tnoib, ntnoi, tempmod

## 噪声 PSD 修正公式

```
标准 BSIM4 闪烁噪声 (P2.7):
  S_flicker = noia * Ids / (freq * Coxe * Leff²)

SKY130 修正 (rnoia, rnoib 是噪声参数的比例因子):
  noia_eff = noia * rnoia   // rnoia 默认 1.0 (不修正)
  noib_eff = noib * rnoib   // rnoib 默认 1.0

温度修正 (tempmod, ntnoi):
  if (tempmod == 1):
    T_factor = (T/300.15)^ntnoi
    S_flicker *= T_factor

热噪声修正 (tnoia, tnoib):
  S_thermal = 4*k*T*(2/3)*gm * tnoia  // tnoia 默认 1.0
  // tnoib 用于沟道热噪声的二次修正 (小项)
```

## 实现位置
float_spice.c mos_thermal_psd() + mos_flicker_psd():
```c
static REAL mos_flicker_psd(REAL ids, REAL coxe, REAL Leff, REAL freq,
                            REAL noia, REAL noib, REAL rnoia, REAL rnoib,
                            REAL ntnoi, REAL tempmod, REAL T) {
    REAL noia_eff = noia * (rnoia > 0 ? rnoia : 1.0f);
    REAL noib_eff = noib * (rnoib > 0 ? rnoib : 1.0f);
    REAL S_f = noia_eff * fabsf(ids) / (fmaxf(freq, 1e-3f) * coxe * Leff * Leff);
    if (tempmod > 0.5f) S_f *= powf(T / 300.15f, ntnoi);
    return S_f;
}
```

## 验证
SKY130 nfet_01v8: rnoia=1.0 → 噪声与标准 BSIM4 一致。设置 rnoia=2.0 → 噪声加倍。
