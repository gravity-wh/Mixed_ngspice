## 测试方法
```bash
for f in test/circuits/mg/*.sp test/circuits/of/*PMU*.sp test/circuits/of/*sky130*.spice; do
  echo "=== $f ==="
  timeout 60 ./float_spice/float_spice "$f" > "/tmp/sky130_$(basename $f).log" 2>&1
  if [ $? -eq 0 ] && ! grep -qi "nan\|error\|singular" "/tmp/sky130_$(basename $f).log"; then
    echo "PASS"
  else
    echo "FAIL"
  fi
done
```

## 成功标准
- 收敛率 ≥60% (SKY130 的 binning/高级效应可能导致部分失败)
- 收敛的电路: 无 NaN, VDD 节点电压正确
- 失败电路: 分类根因 (解析? 参数缺失? 收敛?)
