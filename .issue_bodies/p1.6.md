## 目标
实现完整 BSIM4v5 源漏电阻模型：偏压依赖 (prwg/prwb) + 独立源/漏 (rsw/rdw) + Rds 退化 gm/gds/Ids。完成后高 VGS 下 Ids 精度提升。

## 涉及的参数 (6)
rdsw, rsw, rdw, prwg, prwb, wr

## BSIM4 Rds 模型

### 1. 每侧电阻 (偏压依赖)
```
Rs_per_side = (rdsw + prwg*Vgsteff) / (Weff^wr)  // 栅压依赖
// 独立源漏 (如果提供):
Rs_source = rsw / Weff   // 源端电阻
Rd_drain = rdw / Weff    // 漏端电阻
```

### 2. Rds 退化 (影响 gm, gds, Ids)
```
// 总电阻:
Rtotal = Rs_source + Rd_drain  
// 当前状态只用了单 rdsw, 缺独立 rsw/rdw 和 prwb

// 退化后的 Ids:
// 这是隐式方程, nsgice 用 Newton 迭代求解
// 简化版本:
Vds_int = Vds - Ids*Rtotal
// 用 Vds_int 替代 Vds 重新计算 Ids (1-2次迭代就够)
```

### 3. 退化后的 gm/gds
```
gm_degenerated  = gm / (1 + gm*Rs_source + (gm+gds+gmbs)*Rd_drain)
gds_degenerated = gds / (1 + gm*Rs_source + (gm+gds+gmbs)*Rd_drain)
```
