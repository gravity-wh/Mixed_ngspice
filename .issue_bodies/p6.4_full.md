## 目标
SKY130 应力效应参数 — STI 应力对 Vth 和迁移率的影响。

## 参数 (4): saref, sbref, steta0, stk2

## 应力效应方程

```
SA, SB:  diffusion-to-gate spacing (MOSFET instance params, 已有)

// 参考值归一化:
sa_factor = 1 / (SA + saref) - 1 / (sa_ref + saref)
sb_factor = 1 / (SB + sbref) - 1 / (sb_ref + sbref)

// Vth 应力修正:
ΔVth_stress = stk2 * (sa_factor + sb_factor)
Vth = Vth_basic + ΔVth_stress

// DIBL 应力修正:
Δeta0_stress = steta0 * (sa_factor + sb_factor)
eta0_eff = eta0 + Δeta0_stress
```

## 与 LOD (P6.1) 的区别
- LOD (ku0/kvth0): 影响迁移率和 Vth，用长度依赖的综合 SA/SB 函数
- 应力 (saref/sbref/steta0/stk2): 独立的 SA/SB 参考值修正，主要影响 Vth 和 DIBL
